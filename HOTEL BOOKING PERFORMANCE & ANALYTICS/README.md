# 🏨 Hotel Booking Performance & Analytics Dashboard

An interactive **Tableau dashboard** developed to analyze hotel booking performance, revenue trends, guest behavior, cancellation rates, and market segments. This project demonstrates a complete **data analytics workflow**, beginning with data cleaning and transformation in **Microsoft Excel Power Query**, followed by the creation of an interactive Tableau dashboard to deliver actionable business insights.

## 📌 Project Overview

This project focuses on analyzing hotel booking data to uncover valuable insights into reservation trends, customer behavior, revenue performance, cancellation patterns, and booking sources. The raw dataset was first cleaned and transformed using **Microsoft Excel Power Query** to ensure high-quality and consistent data. The cleaned dataset was then imported into **Tableau** to build an interactive dashboard featuring KPIs, filters, and business-focused visualizations.

## 📊 Key Insights

- City Hotels receive significantly more bookings than Resort Hotels.
- Booking demand peaks during the summer months.
- Online Travel Agencies (Online TA) generate the highest number of bookings.
- Bed & Breakfast (BB) is the most preferred meal option.
- Portugal contributes the largest share of hotel bookings.
- Most bookings are successfully completed, while cancellations account for a significant portion of reservations.
- The repeat guest rate is relatively low, highlighting opportunities to improve customer retention.
